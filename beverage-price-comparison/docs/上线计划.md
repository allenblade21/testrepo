## 阶段 0 · 数据源与合规（业务方行动项，最长周期，立即启动）

1. **企业主体**：三大开放平台入驻均需企业资质；
2. **开放平台入驻申请（建议三家同时提交）**：淘宝开放平台（open.taobao.com）/ 京东宙斯 JOS（jos.jd.com）/ 美团开放平台（open.meituan.com），申请商品类目 API 权限；先批先接（适配器支持单平台先行）；
3. **法务评审**：数据获取边界（平台条款/反不正当竞争）；**广告法**——界面「最便宜」等绝对化用语上线前改为「本次比价最低」；
4. **国内上线资质**：域名 ICP 备案（2~4 周）；采集定位/账号后需隐私政策 + 个保法（PIPL）合规；
5. **过渡验证**：授权落地前，人工抽样 50~100 个真实 SKU 价格录入验证匹配/算价适应性。

## 阶段 1 · 生产化基础 ✅（v0.4.1 交付清单）

| 项 | 交付物 | 验证 |
| --- | --- | --- |
| 容器化 | `Dockerfile`（非 root、HEALTHCHECK）+ `docker-compose.yml` + `.dockerignore` | 配置审查（沙盒无 Docker 守护进程，构建待部署环境验证）|
| CI | `.github/workflows/ci.yml`：每次 push/PR 跑 173 项 pytest + E2E 分页回归 | 首次 push 触发 |
| 数据刷新 | `DataStore` 可重建快照：`POST /admin/refresh`（ADMIN_TOKEN 保护）+ `REFRESH_INTERVAL_S` 定时任务；失败保留旧快照 | 实测 3s 间隔自动重建、401/200 |
| 价格新鲜度 | `/health` 暴露 `snapshot_at/rebuilds`；`/compare` 返回 `price_as_of` | 实测 + pytest |
| 可观测 | 请求结构化日志（方法/路径/状态/耗时/客户端）；`GET /metrics`（请求数/错误数/限流数/P50/P95/P99）| 实测 |
| 基础安全 | 滑动窗口限流（`RATE_LIMIT_PER_MIN`，health 豁免）；CORS（`CORS_ORIGINS`）| 实测 429/豁免 |
| 配置化 | `app/config.py` 环境变量驱动 + `.env.example` | pytest |

**有意不做（记录在案）**：SQLite→PostgreSQL 迁移——沙盒无法验证且 Mock 数据阶段无价值；待真实适配器产生持久增量数据时执行（届时同步引入连接池与迁移工具）。

## 阶段 2 · 真实数据接入（授权后，约 2~4 周/平台）

- 按官方 API 实现真实适配器（`PlatformAdapter` 插座已就绪，上层零改动）；
- 商户主数据映射（同店跨平台异名对齐）+ 人工确认工作流；
- 价格校验抽样 + 误差熔断降级「仅供参考」（对齐 v0.1 NFR：误差 ≤2% 或 ≤1 元）；
- 新鲜度分级：热点 SKU ≤5min / 长尾 ≤30min（刷新机制已就绪，接调度粒度即可）。

## 阶段 3 · 上线必需产品能力（与阶段 2 并行）

1. 定位与配送范围（门店坐标/范围过滤/距离计费）——v0.1 FR-1/FR-2 回补；
2. 跳转下单 Deeplink（转化闭环 = 北极星指标载体）；
3. 库存/营业状态；
4. 载体：H5 先行（微信小程序类目审核严，二期）。

## 阶段 4 · 试点上线（数据打通后 2 周）

- 1 城市 + 饮品品类（优先高标准化连锁：瑞幸/蜜雪等）；
- 验收线：匹配准确率 ≥90%；到手价误差 ≤2% 或 ≤1 元；P95 ≤2s（/metrics 已可观测）；
- 灰度放量 → 「比价结论 vs 实际下单」偏差回流。
