# 复盘（Retrospective / Post-mortem）

记录 bug 复盘与经验教训，供后续避免重复踩坑。测试用例明细见 [测试报告.md](测试报告.md)。

---

## 一、Bug 复盘

### BUG-001 · 到手价可为负（v0.2.1 修复）
- **现象**：误配优惠（如「满5减10」）算出 −¥5.00 的到手价。
- **根因**：满减/券的减免额未封顶于应付金额（仅补贴有封顶）。
- **修复**：算价循环内对**每项**减免统一 `min(减免, 当前应付)`。
- **教训**：金额类计算必须有「不得为负」的封底不变式，并用测试锁死（`test_*_never_drives_price_negative`）。

### BUG-002 · 起送价错误拦截（v0.3.2 修复）
- **现象**：瑞幸美团 ¥17.8（<¥20）被判不可下单，让用户错过真正最便宜的平台。
- **根因**：起送价建成了平台级常量，而现实是商家逐店自设的门店属性。
- **修复**：迁移为 `(商户,平台)` 级（ADR-003）。
- **教训**：建模粒度要匹配现实的归属层级；「平台统一 X」这类假设要用真实数据质疑。这是**用户反馈驱动**发现的（用户直接指出瑞幸应能下单）。

### BUG-003 · 加载更多分页计数错乱（v0.3.3 修复）
- **现象**：输入新词后防抖未触发时点「加载更多」，出现「已显示40 / 共32」。
- **根因**：追加请求读取输入框实时值作查询词，以「新词+旧偏移」请求并覆盖总数。
- **修复**：追加请求钉死列表所属查询词 `curQuery`。
- **教训**：异步竞态普通点击测不出，必须**探针对账 + 精确卡进防抖窗口**才能复现；已固化为 E2E 用例。

### localStorage 整页崩溃（v0.5.2 修复）
- **现象**：iframe 内嵌场景整页白屏（不止定位，搜索/比价全挂）。
- **根因**：`localStorage.getItem` 在内嵌/隐私模式抛异常，且在模块加载顶层执行。
- **修复**：`safeStore` try/catch 封装，降级内存态。
- **教训**：浏览器存储 API 在受限环境会抛异常，任何顶层调用都要容错；**这个 bug 是移动端 E2E 顺带揪出的**——加测试的附带收益远超预期。

## 二、经验教训（做对的 & 该记住的）

### 有效的做法
- **可插拔适配器架构**（ADR-002）：搜索/定位/排名/聚合等多轮功能演进，业务层全部零改动接在 Mock 上，验证了解耦价值。
- **测试哨兵防回归**：`test_catalog_coverage_sentinel` 钉死数据构成，任何数据/匹配改动导致构成变化立即报警。
- **探针对账抓竞态**：分页 bug 靠逐步对账「DOM卡片数==已显示==累计 && 无重复」抓出，比断言最终态更早暴露问题。
- **诚实标注 Mock 数据**：全程界面标注「非真实价格」，避免误导，也便于真实数据接入时定位替换点。
- **参数化测试忠实反映数据分布**：70 个两平台单元→70 条用例；数据补齐后收敛到 3 条——测试数量下降是正确的，不是覆盖变差。

### 环境/操作教训
- **`pkill -f "uvicorn..."` 自匹配杀 shell**：命令行含该字面串会匹配自己 → 用 `[u]vicorn` 括号技巧；kill 与 start 分两条命令。
- **退出码 144 = 被 SIGTERM 杀**（128+信号），是主动停服务的正常结果，非崩溃。
- **Artifact 是 iframe**：定位弹窗、部分权限受 Permissions Policy 限制，真机验证要用独立 HTTPS 页面。
