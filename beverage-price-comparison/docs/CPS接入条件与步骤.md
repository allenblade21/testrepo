- **文档版本**：v0.1

- **关联**：[团餐团购比价需求.md](团餐团购比价需求.md) · [真实上线需求文档.md](真实上线需求文档.md)（P2-1 Deeplink 转化闭环）

## 1. 先分清两种「非商户」接入身份

团购数据的非商户取数,本质是加入平台的**营销分佣体系**,有两类身份:

| 身份 | 是谁 | 拿到什么 | 典型平台叫法 |
| --- | --- | --- | --- |
| **A. 推广者 / 联盟客（流量方）** | 有流量位（App/站/公众号/小程序）想推广团购赚佣金的开发者 | 可推广商品 + 团购价 + 佣金 + **deeplink 推广链接** + 查询 API | 美团联盟「推广者」、淘宝联盟「淘客」 |
| **B. CPS 服务商 / 达人** | 帮商家配置佣金计划的服务商，或带货的达人 | 佣金计划配置、商品数据、核销/结算 | 抖音生活服务「CPS 服务商 / 团购达人」、快手/小红书达人 |

> 本项目要的是**取团购比价数据 + deeplink 跳转**，**A（推广者/联盟客）最契合**；B（服务商/达人）更偏「帮商家运营/带货」，字段更全但门槛与义务更重。

---

## 2. 通用接入总览（五步主线）

不同平台细节各异，但主线一致：

```
① 注册账号 → ② 资质认证（个人/企业）→ ③ 创建媒体 + 推广位（拿 AppKey/渠道标识）
   → ④ 申请 API 授权（拿 AppKey/Secret + 接口权限）→ ⑤ 调接口取团购数据 + 生成 deeplink → 结算佣金
```

- **前置准备**：企业营业执照（多数平台 CPS/API 需企业主体）、对公账户、备案的媒体（App/网站/小程序/公众号）、结算发票能力。
- **时间成本**：资质认证多为即时~数个工作日；API 权限与频次提升需商务/审核，通常更慢。

## 3. 各平台接入条件与步骤

### 3.1 美团联盟（推广者路径，最现成）⭐

**入口**：[union.meituan.com](https://union.meituan.com/)

| 项 | 内容 |
| --- | --- |
| **身份** | 推广者（媒体/流量方），非商户 |
| **资质** | 支持个人 / 企业；**API 与 CPS 提现门槛偏企业**（个人做红包推广门槛低，但 API 授权与规模化偏企业） |
| **步骤** | ① 登录美团联盟 → ② 「账户管理 > 基本信息」完成资质认证（**认证后账户性质不可改**）→ ③ 「推广者备案 > 媒体管理」新增媒体（拿 **AppKey**，渠道追踪标识）→ ④ 「推广者备案 > 推广位管理」新增推广位 → ⑤ 「我要推广 > API 授权」申请接口 |
| **API 能力** | 团单/商品查询接口、推广链接（deeplink）生成；**首次频次 2000 次/天**，可申请提升 |
| **结算** | 入驻后**佣金 T+7 自动结算**；结算中心提现；**月提现上限 3 万**；**个人身份扣 6% 手续费**；规模化/企业结算**需发票** |
| **门槛提示** | CPS 门槛相对高：**企业资质 + 推广费过万才好提现 + 结算需发票**，流程偏繁琐 |

### 3.2 抖音生活服务 CPS（服务商 / 达人路径）

**入口**：[抖音开放平台·生活服务 CPS 接入指南](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/open-capacity/Industry/life/partner/CPS-guide)

| 项 | 内容 |
| --- | --- |
| **身份** | CPS 服务商（帮商家配佣金计划）或团购达人（带货）；**个人开发者不能申请标准 API** |
| **资质** ⭐ | **中国大陆注册企业**；营业执照范围含相关经营；**注册资本 > 50 万**（**团购服务商 > 100 万**）；团购服务商须**具备软件开发能力/相关资质** |
| **佣金计划** | 分**通用计划**（所有达人可推）与**定向计划**（指定达人可推）；**CPS 分佣 1%~29%** |
| **步骤（达人）** | 「团购达人中心」完成入驻 → 选品 → 视频/直播推广 → 查看数据 → 结算 |
| **步骤（服务商）** | 企业资质入驻服务商 → 通过 API 为商家商品配置佣金计划 → 达人推广 → 用户到店核销分佣 |
| **API 能力** | 佣金计划发布/修改、商品线上数据查询（goods/online.query）、团购券码核销 |
| **结算** | 核销订单**直接给达人打款，核销 10 分钟后可提现**；**核销 5 天后**平台与达人可得订单支付金额与分佣金额 |
| **门槛提示** | ⚠️ **团购 CPS 尚未完全对市场开放**，仅少量服务商有接口权限；普通接入常需经第三方服务商 |

### 3.3 阿里妈妈 / 淘宝联盟（承接饿了么 / 口碑 / 高德到店）

**入口**：[aff.alimama.com](https://aff.alimama.com/)

| 项 | 内容 |
| --- | --- |
| **身份** | 淘客（推广者），非商户 |
| **资质** | 支持个人/企业淘客；API 走**淘宝开放平台**淘客接口，需应用注册与权限申请 |
| **能力** | 已整合**饿了么**等本地生活；可推广并拿 CPS；**饿了么聚合页 CPS 6% 起**；订单自动同步到联盟账户 |
| **步骤** | 注册淘宝联盟 → 完成认证 → 在淘宝开放平台建应用取 AppKey/Secret → 申请淘客/本地生活 API 权限 → 取推广链接与数据 |
| **门槛提示** | 到店团购（口碑/高德）开放能力**迁移中**，字段可得性需按当前高德/支付宝体系确认（见需求文档 §12.1） |

### 3.4 快手（磁力聚星 / 生活服务）

**入口**：[磁力聚星 k.kuaishou.com](https://k.kuaishou.com/) · [生活服务 open.kwailocallife.com](https://open.kwailocallife.com/)

| 项 | 内容 |
| --- | --- |
| **身份** | 达人 / 内容带货为主 |
| **现状** | 生活服务开放能力**内测阶段，仅企业开发者**，需联系商务；磁力聚星偏达人营销 |
| **门槛提示** | 生活服务团购分销**开放程度低**，接口成熟度不足，建议二期观望 |

### 3.5 小红书（蒲公英 / 聚光）

| 项 | 内容 |
| --- | --- |
| **身份** | 达人 / 推广者（蒲公英）；商家能力另走开放平台 |
| **现状** | 本地生活「种草→到店」为主，**分销结构化能力建设中，开放有限** |
| **门槛提示** | 团购套餐结构化明细开放度低，早期不作为主数据源 |

| **美团联盟** | 推广者 | API/规模化倾向企业 | 认证后性质不可改；提现需发票、门槛过万 | 团单/商品查询 + deeplink，2000次/天起 | T+7，月提现上限3万，个人扣6% | ⭐⭐⭐ 最现成 |

## 5. 合规与风控（接入前必读）

1. **只走授权路径**：联盟/CPS 是官方授权取数，**严禁爬取前台非授权数据**（违反平台协议与《反不正当竞争法》，见需求文档 §9）。
2. **字段为「带货」设计**：联盟数据以「可推广商品 + 价格 + 佣金 + deeplink」为主，**未必含套餐菜品明细/完整使用规则**；精细比价可能仍需降级（需求文档 §12.2 / §10）。
3. **覆盖非全量**：只拿得到**参与 CPS 推广**的商品，未入联盟的套餐取不到。
4. **应用用途审核**：平台默认你在导购带货，**纯比价类应用可能触及内容/竞争规则或需额外审核**，接入时须如实申报用途。
5. **认证不可逆项**：如美团联盟「账户性质认证后不可改」，选个人/企业前想清楚。
6. **发票与结算义务**：企业结算多需开票，纳入财务合规。

## 6. 对本项目的落地建议

- **G-R1 取数身份优先走美团联盟（推广者）**：门槛最现成、有团单/商品查询 API + deeplink，一步同时解决「数据源」与「Deeplink 转化闭环」（真实上线需求文档 P2-1）。
- **准备材料清单**（企业路径）：营业执照、对公账户、备案媒体（本项目 App/站）、经营用途说明、开票能力。
- **接入顺序**：美团联盟 → 阿里妈妈（饿了么/到店）→ 抖音生活服务 CPS（企业+注册资本达标后）→ 快手/小红书（观望）。
- **菜品明细补全**：联盟字段不足时，对**已合作商家**走「商家授权」路径（需求文档 §12.1 A 路径）补菜品清单。
- **Mock 先行**：架构不阻塞——先按联盟可得字段（餐厅+套餐标题+团购价+人均+deeplink）建 Mock 跑通比价，真实权限到位再替换适配器。

## 7. 待官方确认清单（接入前逐条落实）

1. 美团联盟 API 是否对「**比价类**」应用发放权限？频次与字段范围？
2. 抖音团购 CPS 当前是否对新服务商开放？还是必须经既有服务商？
3. 各平台 deeplink 是否允许**第三方比价场景**使用（而非仅自有内容推广）？
4. 联盟数据中**套餐菜品明细字段**是否存在？缺失比例多大（决定降级范围）？
5. 阿里到店（口碑/高德）团购的开放能力**当前主入口与可用接口**？
6. 各平台对「同时聚合多平台价格对比」是否有竞争性条款限制？
