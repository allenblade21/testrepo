# 安卓本地后端方案（后端跑在安卓设备上）

- **文档版本**：v0.1
- **目标**：把 FastAPI 后端**发布在安卓设备本机**——单机自包含，不依赖电脑/云服务器；与薄壳 APK 组合成「一台平板跑全套」。
- **关联**：[安卓平板测试版方案.md](安卓平板测试版方案.md)（§5 Tier 3 的落地细化）· [App化实施计划.md](App化实施计划.md)
- **配套已入库**：`requirements-android.txt`（精简依赖）· `tools/android_termux_run.sh`（一键脚本）· **代码已支持精简模式**（v0.8.4：reportlab 改为可选依赖）

---

## 0. 方案总览（推荐路线）⭐

**Termux 跑原生 Python 后端 + 薄壳 APK 指向本机**，两步得到单机自包含：

```
┌──────────────────── 同一台安卓设备 ────────────────────┐
│  Termux（Linux 环境）                                   │
│    └─ uvicorn app.main:app --host 127.0.0.1 --port 8077 │
│         ▲ 后端原样运行：比价/团购/CPS 适配器全量代码      │
│  浏览器 或 Capacitor 薄壳 APK                            │
│    └─ server.url = http://127.0.0.1:8077 （本机回环）    │
└─────────────────────────────────────────────────────────┘
```

- **后端代码零改写**：跑的就是仓库里同一份 `app/`；
- **本机回环 127.0.0.1**：不需要局域网、不需要公网、不需要 HTTPS；
- 需要真实 CPS 数据时设备联网 + 环境变量密钥即可（切源/回退机制原样生效）。

## 1. 依赖现实（先认清两个原生扩展）

| 依赖 | 性质 | 精简模式处理 |
| --- | --- | --- |
| `pydantic_core`（FastAPI 依赖）| Rust 扩展 | **绕不开**：Termux `pkg install rust` 后 pip 本地编译（一次性 20~40 分钟）；或用 TUR 源预编译包 |
| `reportlab`（PDF 导出）| C 扩展 | **已做成可选**（v0.8.4）：不装它后端照常启动，`/export` 返回 501 明确降级，其余接口全量可用 |
| uvicorn / httpx / SQLite | 纯 Python / 内置 | 无障碍 |

> 代码侧保障（已入库并有测试锁）：`app/export_pdf.py` 的 reportlab import 包在 try/except 里，`PDF_AVAILABLE=False` 时 `/export` → **501**（不是 500、不是崩溃）。**勿把该 import 挪回硬依赖。**

## 2. 实施步骤（Termux 路线，可复制）

```bash
# ① 平板装 Termux（从 F-Droid 或 GitHub Releases 装，Play 商店版已停更）
# ② Termux 内取代码（git 或直接拷贝仓库目录）
pkg install -y git && git clone <你的仓库地址> && cd testrepo/beverage-price-comparison

# ③ 一键安装（首次；rust 编译 pydantic_core 需 20~40 分钟耐心等）
bash tools/android_termux_run.sh setup

# ④ 起服务
bash tools/android_termux_run.sh start
#    → 本机浏览器开 http://127.0.0.1:8077/（饮品）/discover /test
#    → 团购探针 http://127.0.0.1:8077/api/tuangou/health

# ⑤（可选）薄壳 APK 指向本机：capacitor.config.json
#    "server": { "url": "http://127.0.0.1:8077", "cleartext": true }
#    → 单机自包含 App 体验（GPS 走原生插件）

# ⑥（可选）真实 CPS 数据：设备联网后
export TUANGOU_SOURCE=union,douyin,alimama
export MEITUAN_UNION_APPKEY=... MEITUAN_UNION_SECRET=...
bash tools/android_termux_run.sh start     # 失败自动回退 Mock，服务不挂
```

**常用运维**：
- 后台常驻：Termux 装 `termux-services` 或用 `nohup ... &`；息屏不杀进程需在 Termux 通知里点「Acquire wakelock」；
- 开机自启：装 **Termux:Boot** 插件，把 start 命令放进 `~/.termux/boot/`；
- 跑测试自证：`bash tools/android_termux_run.sh test`（193 项，PDF 相关 2 项在精简模式下按 501 断言通过）。

## 3. 排障速查

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| `pip install pydantic` 报错找不到轮子 | Termux 是 Bionic libc，PyPI 的 manylinux 轮子不适用 | 确认 `pkg install rust binutils` 后重跑（本地编译）；或 `pkg install tur-repo && pkg install python-pydantic` 用预编译包 |
| 编译 pydantic_core 内存不足被杀 | 低内存设备 | 关后台应用重试；或换 TUR 预编译包 |
| `/export` 返回 501 | 精简模式未装 reportlab | 预期行为；需要 PDF 就 `pip install reportlab`（能编译则全量恢复） |
| 服务被系统杀掉 | 安卓后台限制 | wakelock + 关闭 Termux 的电池优化 |
| 薄壳 APK 连不上 127.0.0.1 | cleartext 未开 | config 里 `"cleartext": true`（本机回环无泄露面） |

## 4. 备选路线对比

| 路线 | 形态 | 优点 | 代价 | 判定 |
| --- | --- | --- | --- | --- |
| **Termux** ⭐ | Termux 内跑原生后端 | 代码零改写、全功能、可跑全量测试 | 手动装一次环境；非「点一个图标」 | **首选**，先验证依赖能跑 |
| **Chaquopy 单 APK** | CPython 嵌进 APK，前后端一个安装包 | 分发体验最好（装完即用） | Gradle 集成工作量大；pydantic v2/reportlab 须在其包仓库有，版本可能滞后 | Termux 验证通过后、确需「一个 APK」再做 |
| Pydroid 3 | 商店 App 内跑脚本 | 最快手动验证 | 不可分发、不可自启 | 仅个人快测 |

## 5. 诚实边界

1. **本沙盒无安卓环境**，以上是可执行 runbook 而非「已在真机跑通」；关键不确定点只有一个——**pydantic_core 在你设备上编译/安装成功**（rust 路线或 TUR 预编译二选一），装上即赢，其余全是纯 Python。
2. 精简模式 `/export` 降级为 501 是**刻意设计**（可选依赖），不是缺陷；设备上装得动 reportlab 就自动恢复全量。
3. 本机 127.0.0.1 明文 HTTP 仅限单机回环，**不要**把它 `--host 0.0.0.0` 暴露到公网。
4. 真实 CPS 拉数需设备联网 + 密钥；离线时走 Mock（回退机制自动处理）。
