# 比价系统 · 数据字典（关键输入字段）

本文件定义比价所需的**核心数据实体与字段**，即需求文档中所说的「细节输入」。字段是到手价计算与跨平台匹配的基础，采集/适配层须将各平台数据归一化为下列统一模型。

- **关联文档**：[需求文档.md](需求文档.md) · [系统架构.md](系统架构.md)
- **约定**：`必填=M` / `选填=O`；价格金额统一以「分」存储，展示时换算为「元」。

---

## 1. 平台（Platform）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| platform_id | string | M | 平台唯一标识，如 `alibaba_flash` / `meituan` |
| platform_name | string | M | 展示名（阿里闪购 / 美团）|
| category_scope | enum[] | M | 覆盖品类：餐饮 / 商超 / 生鲜 … |
| source_type | enum | M | 数据来源：official_api / compliant_crawl |
| status | enum | M | 接入状态：enabled / degraded / disabled |

---

## 2. 门店（Store）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| store_id | string | M | 平台内门店 ID |
| platform_id | string | M | 所属平台 |
| brand_id | string | O | 品牌 ID（用于跨平台同品牌对齐）|
| brand_name | string | M | 品牌/店名 |
| category | string | M | 品类（奶茶/快餐/商超/生鲜…）|
| geo (lng,lat) | geo | M | 门店坐标 |
| delivery_range | geo/number | M | 配送范围（多边形或半径）|
| min_order_amount | int(分) | M | 起送价 |
| base_delivery_fee | int(分) | M | 基础配送费 |
| rating | decimal | O | 门店评分 |
| est_delivery_minutes | int | O | 预计送达时长 |
| business_status | enum | M | 营业中/休息/停业 |

---

## 3. 可比单元（ComparableUnit）— 跨平台匹配关系

将不同平台代表「同一商品/餐品」的条目关联在一起，是比价的桥梁。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| unit_id | string | M | 可比单元唯一 ID |
| canonical_name | string | M | 归一化标准名 |
| canonical_spec | string | M | 归一化规格/份量 |
| barcode | string | O | 条码（商超类强匹配主键）|
| item_refs | ref[] | M | 各平台商品条目引用（见 §4）|
| match_confidence | enum | M | exact / probable / single_side |
| match_signals | json | O | 匹配依据（条码/名称相似度/图片…）|
| review_status | enum | O | 自动/待人工/已确认/已纠错 |

---

## 4. 商品·餐品条目（Item）— 平台侧原子数据

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| item_id | string | M | 平台内 SKU/餐品 ID |
| platform_id | string | M | 所属平台 |
| store_id | string | M | 所属门店 |
| name | string | M | 商品/餐品名称 |
| spec | string | M | 规格（大杯/500ml/500g…）|
| unit | string | M | 单位（份/件/kg）|
| attributes | json | M | 口味/温度/加料等属性（保证「同款」）|
| list_price | int(分) | M | 标价/原价 |
| sale_price | int(分) | M | 当前售价（店铺直降后）|
| stock_status | enum | M | 在售/售罄/下架 |
| package_fee | int(分) | O | 打包/餐盒费（单品级，如有）|
| image_url | string | O | 商品图（辅助匹配/展示）|
| updated_at | datetime | M | 价格数据时间戳（新鲜度）|

## 5. 优惠（Promotion）— 到手价关键变量

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| promo_id | string | M | 优惠 ID |
| scope | enum | M | 作用域：platform / store / item |
| type | enum | M | 满减 / 直降 / 第N份 / 秒杀 / 平台补贴 |
| threshold | int(分) | O | 门槛金额（满 X）|
| discount_value | int(分)/rate | M | 减免额或折扣率 |
| stackable_rule | json | M | 与其他优惠的叠加/互斥规则 |
| calc_order | int | O | 参与到手价计算的先后顺序 |
| valid_from/to | datetime | M | 生效时间窗 |
| applicable_scope | json | O | 适用商品/品类范围 |

## 8. 用户与上下文（UserContext）

| --- | --- | --- | --- |

## 9. 比价结果（ComparisonResult）— 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| unit_id / cart_id | string | 单品或整单标识 |
| per_platform[] | json | 每平台：到手价 + 明细（标价/各优惠/配送/打包）|
| cheaper_platform | string | 更便宜的平台 |
| savings_amount | int(分) | 节省金额 |
| savings_rate | rate | 节省比例 |
| deeplink[] | string | 各平台跳转下单链接 |
| price_confidence | enum | 精确 / 仅供参考（超误差阈值降级）|
| computed_at | datetime | 计算时间 |

## 10. 到手价明细示例（透明展示）

```
一点点·招牌奶茶（大杯/正常糖/去冰）

               阿里闪购        美团
标价            18.00          18.00
店铺满减       −3.00          −2.00
平台补贴       −2.00          −4.00
优惠券         −1.00（店铺）  −3.00（平台，门槛已达）
配送费         +2.00          +0.00（会员免配送）
打包费         +1.00          +1.00
─────────────────────────────────────
到手价          15.00          10.00   ← 更便宜（省 5.00 / 33%）
```

> 上表为口径演示，数值非真实数据。实际取数与规则以 M1 阶段可获得的平台数据能力为准。
